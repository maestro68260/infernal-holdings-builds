# Dreams Corporations: Infernal Holdings — builds de test

**Ce dépôt ne contient aucun code.** Il ne sert qu'à publier les versions de test du jeu,
pour que les testeurs puissent télécharger sans compte GitHub.

## Télécharger

Onglet **Releases** (à droite) → la dernière version → `DreamsCorporations_test.zip`.

1. Dézipper où tu veux (le jeu ne s'installe pas, il n'y a pas de registre).
2. Double-cliquer `InfernalHoldings.exe`.
3. Windows va afficher « Windows a protégé votre ordinateur » : **Informations complémentaires
   → Exécuter quand même**. C'est normal, l'exécutable n'est pas signé (pas de certificat).
4. **Échap** passe la vidéo d'introduction.

## Rapporter un problème

Les issues de ce dépôt sont fermées : les retours passent par le canal privé habituel
(Discord ou mail), avec si possible le fichier de trace :

```
%APPDATA%\Godot\app_userdata\Dreams Corporations - Infernal Holdings\trace_jeu.log
```

Ce fichier dit exactement où le jeu s'est arrêté.

## Ce qu'il y a dedans

Un prototype jouable de gestion : on achète des parts d'entreprises en Enfer, on négocie avec
des actionnaires damnés, on fait voter des lois dans sept Cercles, on finit Directeur Général.
Tout est en français. Le jeu est gratuit et le projet est bénévole.
